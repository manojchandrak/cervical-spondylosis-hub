# Cervical Spondylosis Hub

An educational resource for living with cervical spondylosis (neck arthritis): guided,
animated exercises, diet guidance, a daily routine, a symptom checker with red-flag warnings,
a specialist/pain-management locator, Reddit support communities, and motivational quotes.

Live at: https://manojchandrak.github.io/cervical-spondylosis-hub/

## Pages

- **Home** — overview and featured exercise routine callout
- **Exercises** — 8 guided mobility/strength/stretch exercises with animated SVG diagrams and a
  built-in timer
- **Diet** — anti-inflammatory foods, foods to limit, and key nutrients for spine health
- **Daily Routine** — posture, ergonomics, and habits through the day and at bedtime
- **Symptom Checker** — a quick, non-diagnostic self-check plus red-flag warning signs
- **Find Care** — geolocation-based Google Maps search for spine specialists, physiatrists,
  physical therapists, pain management clinics, neurologists, and chiropractors near you
- **Support Groups** — links to relevant Reddit communities
- **Motivation** — curated quotes about health and resilience

## Stack

React 19 + TypeScript + Vite, react-router-dom (hash history, for static GitHub Pages hosting).

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Deploys automatically to GitHub Pages via GitHub Actions on push to `main`.
